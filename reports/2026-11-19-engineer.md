"V4_EPRE_Signals ran Thu 11-19 12:40 but FAILED (result 1)" — same event.

Cause (pinned): `StockAnalysis-V4\epre\paper.py:233`
```python
rows = rows[[(t, r) not in held for t, r in zip(rows["ticker"].astype(str), rows["report_day"].astype(str))]]
```
When `rows` is EMPTY (no new qualifying earnings entries for the day — expected in the mid-November
inter-earnings lull, or all candidates already in the ledger), the list comprehension evaluates to `[]`.
Pandas treats `df[[]]` (indexing with an empty **list**) as **column selection**, returning a frame with
ZERO columns. That silently drops every column including `posted`. `_lines()` then does
`buys["posted"]` at `paper.py:185` → `KeyError: 'posted'` (full traceback in
`StockAnalysis-V4\data\logs\epre_signals_task.log`).

Proof the diagnosis is exact: the crash is at line 185, not at `return out[COLS]` (line 181). So
`_new_rows` DID return a frame containing `posted`; the column was lost downstream. The only downstream
step that can drop columns is line 233's empty-list selection. Line 230 uses `.isin(...)` (returns a
boolean Series → safe row filter even when empty); only line 233 uses a raw Python list, which is unsafe
when empty. This is why it ran fine 2026-10-26..11-18 (every day had ≥1 new entry) and first crashed today.

Impact: EPRE posted no signals today and wrote no ledger rows (the crash is before `save_ledger`), and it
will crash again EVERY zero-entry day until fixed — likely several days through the earnings lull. It also
blocks EPRE real-price capture on those days.

I cannot fix it (V4 is a live folder, hard limit #2) and cannot write a proving test against V4 code. See

## Proposals for the user
1. **Fix the EPRE zero-entry crash (one line, V4).** In `StockAnalysis-V4\epre\paper.py:233`, wrap the
   comprehension in a boolean numpy array so an empty result filters rows (not columns) — the same idiom

   ```python
   held = set(zip(led["ticker"].astype(str), led["report_day"].astype(str)))

                    for t, r in zip(rows["ticker"].astype(str), rows["report_day"].astype(str))], dtype=bool)
   ```
